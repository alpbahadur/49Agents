Keyboard cheatsheet

Hold Tab and press a key. Everything here also has a button or menu equivalent.

Panes

Tab+AOpen the add-pane menu
T N F G B W D CPick a type while the menu is open
Shift+clickPlace several panes in a row
Tab+WClose the focused pane
Tab+QCycle through panes

Navigate

Tab TabMove mode, then WASD and Enter
Tab+1..9Jump straight to a pane or project
Ctrl+scrollZoom the canvas
Ctrl++/-/0Zoom the focused pane
Tab+MMinimap
Tab+PProjects sidebar

Agents

Shift+clickSelect terminals for broadcast
EscClear the selection
Ctrl+Shift+@Mention a file, page or issue into a terminal
Tab+UClaude usage limits
Tab+DMachines panel

Workspace

Tab+SSettings
Tab+HHide every overlay
Tab+`Next tab in a tab group
Tab+=New tab in a tab group
Ctrl+SSave the focused file pane
