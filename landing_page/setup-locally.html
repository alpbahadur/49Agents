Self-hosted

Set up 49Agents locally

Run the full stack on your own machine. No account needed, no data leaves your network.

Prerequisites

  • Node.js 18+
  • tmux
  • ttyd

Quick start

Clone the repo and run the setup script. It handles dependency installation, client build, and process startup automatically.

git clone https://github.com/49Agents/49Agents.git cd 49Agents ./start.sh

The script will prompt you once: single machine or multi-machine. Everything else is automatic.

Single machine

Choose Single machine when prompted. The server starts on port 1071 by default.

Open http://localhost:1071 in your browser once startup completes.

Multi-machine

Run the cloud server on one machine and the agent on another. When prompted, select from three options:

  • Cloud only
  • Agent only
  • Both

Useful with Tailscale for private network access across machines without exposing ports to the internet.

Authentication

No login required for local single-user setups. The server runs open by default.

For multi-user deployments, add GitHub or Google OAuth credentials via environment variables. See the configuration section below.

Agent CLI

The 49-agent command connects agents to the server from any machine.

# Connect in foreground 49-agent start # Connect as a background daemon 49-agent start --daemon # Set a custom host and port 49-agent config # Check connection status 49-agent status # Stop a background agent 49-agent stop # Print systemd / launchd install instructions 49-agent install-service

Configuration

Set these via environment variables or a .env file in the project root.

Variable Default Description
PORT 1071 HTTP port the server listens on
HOST 0.0.0.0 Network interface to bind
JWT_SECRET Secret used to sign user session tokens
AGENT_JWT_SECRET Secret used to sign agent connection tokens
GITHUB_CLIENT_ID GitHub OAuth app client ID
GITHUB_CLIENT_SECRET GitHub OAuth app client secret
GOOGLE_CLIENT_ID Google OAuth client ID
GOOGLE_CLIENT_SECRET Google OAuth client secret
DATABASE_PATH Path to the SQLite database file
