Open source

Self-host it. Own it.

49Agents is fully open source. Clone it, run it on your own hardware, and no data ever leaves your machine. No account, no subscription required.

1 Clone the repo
git clone https://github.com/49Agents/49Agents.git
2 Run the setup script
cd 49Agents && ./start.sh Installs deps, builds assets, asks single vs. multi-machine, starts everything.
3 Open localhost:1071 in your browser
4 Start coding.
