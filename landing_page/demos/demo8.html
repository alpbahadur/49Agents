What is it

A shared workspace for parallel AI work

49Agents gives you an infinite 2D canvas where each tile is a live agent session, terminal, git view, or notepad. You arrange them however you want, across as many machines as you have.

Infinite canvas

Pan and zoom to see all your agents at once. No more hunting across terminal tabs.

Multi-machine

Connect any number of machines. Each runs its own agents. One canvas sees all of them.

Open source

Self-host on your own infra. The agent runner, canvas server, and UI are all open source.

Cloud option

Use app.49agents.com if you'd rather not manage infra. Same features, no setup.

Who it's for

Built for engineers who run AI agents at scale

If you're already using Claude Code or similar tools, you know the problem: agents are useful one at a time, and chaos at five.

💻

Solo developers with multiple machines

Your laptop, a cloud VM, and a beefy desktop can all run agents in parallel — and you can watch them from one screen.

👥

Small engineering teams

Share a canvas with teammates. Everyone sees the same live agent sessions, terminals, and git state.

⚙️

Teams running automated AI pipelines

Dispatch batches of tasks to agent workers across machines and monitor them without writing custom dashboards.

How it works

Up and running in three steps

Self-hosting takes about five minutes. Cloud is instant.

1

Install the agent runner on each machine

Run npx 49agents connect on every machine you want to include. It registers the machine and starts accepting task dispatches.

2

Open your canvas

Log in at app.49agents.com or open your self-hosted instance. All connected machines appear as available nodes.

3

Launch agents and arrange tiles

Spawn a Claude Code session, drop a terminal tile next to it, and add a git diff view alongside. Arrange everything spatially — the canvas remembers your layout.

Features

Everything you need to manage parallel agents

No external dashboards, no duct-tape scripts. It's all built into the canvas.

🖥

Live terminal tiles

Real terminal sessions embedded directly in the canvas. Run commands, watch output, scroll history — without leaving the view.

🌿

Git panel

See branch, diff, and commit status for any repository on any connected machine. All in the canvas, updated live.

📋

Notepad tiles

Drop a markdown notepad anywhere on the canvas. Use it for task context, agent prompts, or quick notes shared with your team.

📊

Resource monitoring

CPU, RAM, and agent load for each connected machine. Pin a resource tile next to any agent session to catch runaway processes immediately.

🔁

Task dispatch

Send a prompt to one agent or fan it out to five machines in parallel. Results come back in their own tiles, side by side.

🔒

Runs on your infra

Self-hosted means your code, keys, and agent sessions never leave your machines. Cloud mode encrypts everything in transit and at rest.
