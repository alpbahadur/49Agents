Features

Everything parallel AI development needs

Not a dashboard on top of your tools — an actual workspace that replaces juggling them.

Infinite Canvas
Pan and zoom across all your work, like a whiteboard that runs code
Place terminals, git views, notes, and monitors anywhere. Zoom out to see everything, zoom in to focus. Your layout persists across sessions.
Multi-machine
One canvas, many machines — local, cloud, or remote servers
Connect your local machine alongside EC2 instances, Hetzner boxes, or any SSH-accessible host. All terminals appear on the same canvas.
Parallel Agents
Run dozens of Claude Code sessions without losing track of any of them
Each AI coding agent runs in its own labeled panel. See which is thinking, which is writing code, and which is waiting — at a glance.
Git Integration
See branch status, diffs, and commit history next to the agent that made the changes
Pin a git panel next to any terminal. No context switching to a separate Git GUI. Changes show up live as agents write code.
Resource Monitoring
Know which machine is overloaded before your agent job crashes
Live CPU, RAM, GPU, and disk usage for every connected machine, displayed as panels you place wherever makes sense on your canvas.
Canvas Notes
Sticky notes that live next to the code they belong to — not in a separate app
Write context, decisions, and todos directly on the canvas. Tag them, move them, reference them without switching applications.

Setup

Self-hosted in three steps

Or skip this and use the cloud version at app.49agents.com — your choice.

1
Clone the repo and install dependencies
git clone https://github.com/49agents/49agents
cd 49agents && npm install

Requires Node.js 18+ and npm 9+

2
Configure your machines
# Copy the example config and edit your machine list
cp config.example.yml config.yml
nano config.yml

Add SSH credentials for remote machines, or keep localhost only

3
Start the server and open the canvas
npm start
# Open http://localhost:4900 in your browser

Access from any browser on your network — works on desktop, tablet, large screen
