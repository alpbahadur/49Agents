Chapter 1 — The problem

You run AI agents.
They live in terminals.
Terminals multiply.

Sound familiar? You spawn Claude Code on one machine, another agent on a second, a third for tests. Now you have eight terminal windows across three SSH sessions. You lose context, miss errors, can’t compare outputs. Managing the agents takes more time than the work they’re doing.

Chapter 2 — The idea

What if every agent lived on one infinite canvas?

Instead of tabs and windows, you get a zoomable 2D surface. Drag terminals. Pin notes. Watch resource graphs. Every agent, every machine, right there — spatially organized however makes sense to you.

Chapter 4 — Getting started

3 commands to start

Self-host in under two minutes. No Kubernetes, no cloud account, no credit card.

1

Clone the repo

$ git clone https://github.com/49agents/49agents
2

Install & build

$ cd 49agents && npm install
3

Launch

$ npm start
✓ Canvas running at http://localhost:3000
